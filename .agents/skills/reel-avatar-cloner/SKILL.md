# Reel Avatar Cloner

Replicates viral Reels/TikToks with **`@Eva`** while keeping real UI / MacBook / B-roll segments 100% authentic (never regenerated by AI) and letting the user run **Google Flow (`Omni 1.2 Flash`) manually** to control credits and quality.

All scripts and bundled assets live inside this skill folder:
- CLI pipeline: [scripts/reel_cloner.py](./scripts/reel_cloner.py)
- Google Flow prompt, anti-filter & eye-gaze rules: [references/flow-prompts-and-safety.md](./references/flow-prompts-and-safety.md)
- CTA & DM conversion funnel by platform: [references/cta-and-dm-funnel.md](./references/cta-and-dm-funnel.md)
- Dual audio matching & TikTok sound search: [references/audio-and-sound-matching.md](./references/audio-and-sound-matching.md)
- Assets (`Eva` references + iOS emoji PNGs: `crying`, `skulls`, `stars_trio`, `persevere`): [resources/](./resources/)

## Core Principles

1. **Never regenerate B-roll / UI screens in AI.** Keep real laptop/phone segments, recover the real pixels behind overlaid English captions via **4-DOF temporal screen reconstruction (`temporal_4dof`)**, and burn aligned Italian captions over them.
2. **Never use single-frame 2D Telea (`telea`) across moving laptop UI cards.** Telea pulls dark lines or adjacent card edges vertically, creating Voronoi/bubble distortions around replaced text. Always clean handheld/panning screen B-roll using **`mode: "temporal_4dof"`** (`cv2.estimateAffinePartial2D` donor alignment + ring illumination matching + horizontal scanline fallback for UI state/hover switches). Keep `telea` only for static pill interiors or Avatar reference clips sent to Google Flow.
3. **Stepped black rounded pills (`Genio: ...`) stay clean with exact overlap.** Clean the English pill pixels with `pill_telea` strictly *inside* the replacement black pill's outer coordinates so zero blurred Telea boundary is ever exposed.
4. **Always strip audio (`-an`) from all video clips** (save `audio_originale.mp3` separately; on final audio muxing NEVER use `-shortest`, so a slightly shorter MP3 never cuts off the last video frames).
5. **Prevent "Fake AI Eyes" BEFORE generating:** Inspect the reference clip's exact gaze trajectory, always apply the **Head-Lead Rule** + **Single-Target Gaze Lock** + `camera-left / camera-right` viewer coordinates, and never contradict the reference video's gaze direction.
6. **Never automate Google Flow clicks.** Hand back clean reference clips + copy-paste prompts and wait for the user's generated MP4.
7. **NEVER reveal the promoted app name (`Freebuff` / `#freebuff`) in social captions, hashtags, or CTA text.** The entire funnel depends on the curiosity gap so viewers follow and comment `"promo"` to receive the app name/link. Keep captions natural (`ig-human` verified: 0 machine tells, <= 3–4 hashtags, `ADV` + AI-generated disclosure).
8. **CTA differs by platform:** Instagram/Facebook = `commenta "promo"` (auto-DM via LinkDM). TikTok has no comment-to-DM (API limit, EU accounts restricted), so the TikTok cut uses `scrivimi "promo" in DM` and the user replies to DMs manually or with native auto-replies. Render a separate TikTok variant of the final reel. Details and the DM message: [references/cta-and-dm-funnel.md](./references/cta-and-dm-funnel.md).
9. **Dual Audio Discovery Strategy:** Always provide both:
   - **Metodo 1 (Ricerca Diretta Suono Meme):** In app su TikTok/IG, scheda "Suoni", cercando il testo dell'hook (es. `"genio tre desideri"`) si trova il suono già pre-tagliato dalla community per quel trend.
   - **Metodo 2 (Brano Ufficiale + Forbici ✂️):** Titolo ufficiale Shazam + offset Forbici al millisecondo (es. `Took Her To The O` a `00:07.86`). Dettagli: [references/audio-and-sound-matching.md](./references/audio-and-sound-matching.md).

## Phase 1 — When the User Uploads a Reference Video to Clone

Create a clean working directory inside the project (e.g. `freebuff-export/<campaign-slug>/`) and run:

1. **Inspect & analyze exact frame boundaries (including subtle screen cuts & whip-pans):**
   - Run:
     ```bash
     python scripts/reel_cloner.py analyze <source.mp4> --workdir <workdir>
     ```
   - Inspect `analysis.json` (`cuts` + OpenCV `diff_events`) AND check boundary frames (`read_file` + bright-outlined text pixel check) to catch:
     - **Subtle UI-to-UI cuts** that score `< 0.25` in FFmpeg scene detection (e.g., dark MacBook UI cutting to dark UI).
     - **Whip-pan transition frames** between UI cuts where no center caption appears in the original (`0..1`, `31..32`, `59`, `87..88`, etc.).
     - **Mid-clip text/pill switches** (e.g., quote disappearing and top pill changing right on the audio beat) and **UI popup/hover state changes** so `temporal_4dof` splits at state boundaries cleanly.
   - Split into mute (`-an`), normalized `720x1280` `30fps` segments:
     ```bash
     python scripts/reel_cloner.py split <source.mp4> --cuts "0:6.0,6.0:end" --scale 720x1280 --workdir <workdir>
     ```

2. **Measure exact bounding boxes (`x0,y0,x1,y1`) & clean B-roll with `temporal_4dof`:**
   - For **MacBook / PC B-roll**, write `clean_p2.json` with:
     - Separate `"mode": "temporal_4dof"` entries per sub-clip and per UI state (`start_frame`, `end_frame` 1-based), setting `"min_y"` if delicate UI text sits right above the label, `"track_y"` excluding browser chrome if a popup closes mid-clip, and `"force_horiz_x_lt"` on frames with a partial left-side hover state change.
     - Optional `"mode": "pill_telea"` keeping clean rects strictly inside the replacement Italian pill bounds.
   - Run:
     ```bash
     python scripts/reel_cloner.py clean <workdir>/clips/parte2_ref_raw.mp4 --out <workdir>/clips/parte2_clean.mp4 --config <workdir>/clean_p2.json
     ```
   - Clean any **Avatar** reference clip (`parte1_ref_clean.mp4`) using `mode: "telea"` / `pill_telea` so Flow inherits pose/lighting without text artifacts.
   - **Mandatory check:** Extract frames from every sub-clip (especially over bright UI cards) and view with `read_file` to verify zero distorted contours.

3. **Render translated Italian captions matched to original geometry (`captions_p2.json`):**
   - Measure the original English caption's exact **`cy_center`** (`(y0+y1)//2`) and height, then configure each Italian card to match (`font_size`, `cy_center`, `font: "arialbd"` or `segoeuib`) so the new text covers the cleaned band naturally and NEVER overlaps below-UI elements or leaves the old top/bottom strip exposed.
   - Match whip-pan skip frames (`start_frame` after motion blur settles) and staggered sub-CTA appearance frames; replace English CTAs (`(comment link)`) with `seguici e commenta "promo" / per ricevere l'app`.
   - For top pills, add a `"pill"` card (`"line1": "Genio:"`, `"emoji1": "stars_trio"`, `"line2": "hai ancora 3 desideri"`).
   - Run:
     ```bash
     python scripts/reel_cloner.py caption <workdir>/clips/parte2_clean.mp4 --out <workdir>/clips/parte2_italiano.mp4 --config <workdir>/captions_p2.json
     ```
   - Verify one frame per sub-clip via `read_file`.

4. **Draft Google Flow prompts (`Omni 1.2 Flash`, `9:16`, `x1`) for Avatar segments ONLY:**
   - Read [references/flow-prompts-and-safety.md](./references/flow-prompts-and-safety.md).
   - First extract `orig_eyes_sheet.png` across the reaction/transition window of `parte1_ref_clean.mp4` to observe exact eye direction (`camera-left` / `camera-right` / upward / lens) and timing (`0.0s–T_switch` -> `T_switch–end`).
   - Provide **Template A (with `parte1_ref_clean.mp4` + `eva_front_single.png`)** AND **Template B (Bulletproof Anti-Filter, character sheet only)**, applying Head-Lead, Single-Target Gaze Lock, `camera-left / camera-right` viewer coordinates, and zero filter-trigger words (`no bedroom/bed/tank top/girl/lips/chestnut`).

## Phase 2 — When the User Uploads the Generated `@Eva` Clips

1. **Inspect quality & eyes BEFORE burning captions:**
   - Run `ffprobe` to verify resolution (`360x640` / `720x1280`), fps (`24` / `30`), and duration.
   - Extract an **eye-transition contact sheet** (`3.75s` to end every `3` frames) and view with `read_file`:
     - Verify eyelids part smoothly without upward white-sclera rolling (`f114`-type roll) and eyes hold a steady natural gaze without sideways marble sliding in the final `0.5s`.
     - If minor roll/tail drift exists, perform a zero-credit surgical resample (excise only the bad 2–3 lid-roll or tail-drift frames and hold/ease the clean open-eye window) before upscaling.
2. **Apply Italian captions & upscale cleanly** (`720x1280`, `30fps`, Lanczos, `-an`):
   ```bash
   python scripts/reel_cloner.py caption <eva_p1.mp4> --out <workdir>/clips/parte1_italiano.mp4 --config <workdir>/captions_p1.json
   ```
   Verify `p1_ita` beat-before (`f50`) and beat-after (`f170`) frames with `read_file` to confirm top pills never cover Eva's eyes/glasses and inline emojis have snug kerning (`emoji_persevere.png` -> `"persevere"` + `"suffix": "\""`).
3. **Assemble both final deliverables (no `-shortest` audio truncation):**
   ```bash
   python scripts/reel_cloner.py assemble \
     --parts <workdir>/clips/parte1_italiano.mp4 <workdir>/clips/parte2_italiano.mp4 \
     --out <workdir>/clips/FINAL-REEL-EVA-ITALIANO.mp4 \
     --audio <workdir>/clips/audio_originale.mp3 \
     --out-audio <workdir>/clips/FINAL-REEL-EVA-ITALIANO-CON-AUDIO.mp4
   ```
4. **Verify, identify exact TikTok audio, & ship:**
   - Confirm exact matching frame count (`e.g. 295 frames`, `9.833s`), `720x1280`, `30/1 fps`, `[video]` on mute vs `[video, audio]` on muxed via `ffprobe`.
   - Execute the **Dual Audio Discovery Strategy** ([references/audio-and-sound-matching.md](./references/audio-and-sound-matching.md)):
     ```bash
     python scripts/reel_cloner.py find-audio <workdir>/clips/audio_originale.mp3 --hook "<testo hook, es: genio tre desideri>"
     ```
     - **Metodo 1 (Ricerca Diretta Suoni TikTok / Instagram):** Istruisci l'utente a cercare nella scheda **Suoni** dell'app la frase dell'hook (es. `"genio tre desideri"`): il trend della community ha il suono già pre-tagliato e sincronizzato.
     - **Metodo 2 (Brano Ufficiale + Forbici ✂️):** Fornisci il titolo/remix ufficiale identificato da Shazam e il timestamp esatto delle Forbici (es. `00:07.86`) con i drop dei beat, testando `asetrate=48000*1.23` se la traccia TikTok era rallentata/tape-slowed.
   - Draft the **TikTok & Instagram captions** (strictly **NEVER mentioning `Freebuff` or `#freebuff`**, hooking on the meme + `seguici e commenta "promo"` + 3 search hashtags), validate with `ig-human` (`humanize.py --report` -> 0 machine artefacts, 0 structural tells), and remind the user to enable the **AI-generated content** toggle + `ADV` disclosure.
